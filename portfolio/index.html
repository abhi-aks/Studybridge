LLM Agent · Self-correcting

Text-to-SQL Agent

Plain English in, MySQL out. The agent writes a query, runs it against a live database — and when it fails, it feeds the error message back to the LLM for a self-correction retry. Schema-aware prompting with hand-verified join relationships keeps a 70B model honest about someone else's data model.

  • Python
  • Groq · Llama 3.3 70B
  • MySQL
  • Prompt Engineering
  • Error-feedback loop

About

The fastest way to learn AI isn't another course — it's shipping something real and fixing what breaks.

I'm Abhishek — an international student in Germany working across applied AI and data engineering. I follow one rule: every concept I learn has to end up inside a working system.

That rule became StudyBridge, a RAG assistant for students at TH Bingen; a text-to-SQL agent that debugs its own queries; and an ongoing mission to predict Deutsche Bahn delays — ambitious, I know.

  • 01

    Ship, don't stash

    Projects go to production — Hugging Face, Docker — not into forgotten notebooks.

  • 02

    Measure, don't guess

    RAGAS metrics for retrieval quality, error-feedback loops for SQL generation. Vibes are not an eval.

  • 03

    End to end

    Ingestion, retrieval, prompting, evaluation, deployment — the whole pipeline, not one segment.
